# Проверка на Android-устройстве

## Сценарии

1. Запустить приложение. Нажать «Открыть PDF», выбрать PDF из Downloads. Дождаться первой страницы.
2. Прокрутить многостраничный документ; проверить стрелки и переход по номеру. Первая и последняя страницы не должны позволять выйти за границы.
3. Развести два пальца, затем свести их. Проверить увеличение и уменьшение. При увеличении провести одним пальцем по диагонали: страница должна двигаться по обеим осям одновременно. Проверить кнопки масштаба и «По ширине».
4. Повернуть телефон на другой странице. Должны сохраниться документ и позиция.
5. Нажать Share, выбрать Telegram / WhatsApp / почту. Проверить имя файла и возможность открыть полученное вложение. Контрольная отправка выполняется пользователем.
6. В файловом менеджере выбрать PDF → «Открыть с помощью» → Simple PDF Reader.
7. Из другого приложения отправить PDF через Share → Simple PDF Reader. Повторить при уже открытом документе.
8. Открыть файл из облачного провайдера системного диалога. Убедиться, что ожидание загрузки и отмена работают.
9. Открыть повреждённый, пустой PDF и PDF с паролем. Должно появиться объяснение с возможностью выбрать другой файл.
10. Проверить большой PDF, отмену открытия и быстрый переход к другому документу. Интерфейс должен оставаться отзывчивым.
11. Сменить системную тему. Проверить панели и читаемость текста; оригинальные цвета страниц PDF должны сохраниться.
12. Проверить небольшой экран, горизонтальную ориентацию и увеличенный системный шрифт.
13. Вернуться на главный экран и открыть «Недавние документы». Открыть файл из списка. Перезапустить приложение и убедиться, что список сохранился.

## Команды

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest # Требуется Android-устройство или эмулятор.
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Robolectric проверяет файловые intent и интерфейс локально. UI-тесты используют тестовое изображение страницы вместо системного PDF-движка. Тесты из `androidTest` проверяют настоящий PdfRenderer на устройстве. Автотесты не заменяют проверку реального системного файлового диалога и конкретных мессенджеров на телефоне.
