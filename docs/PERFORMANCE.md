# Размер и производительность 0.3.1

Измерено 12 ноября 2026 года.

## Размер

| Универсальный подписанный APK | Размер |
| --- | ---: |
| 0.3.0 | 12 568 277 байт |
| 0.3.1 | 1 331 999 байт |

Уменьшение — **89,4%**, примерно в 9,4 раза. Размер указан для файла APK, а не для установленного приложения или сохранённых PDF. Набор поддерживаемых архитектур не сокращался.

В release включены R8, оптимизирующие стандартные правила и удаление неиспользуемых ресурсов. Убрана неиспользуемая прямая зависимость `ui-tooling-preview`. Большую часть исходного APK занимал DEX-код библиотек, включая неиспользуемые иконки; теперь недостижимый код удаляется. Основа настройки — [официальная инструкция Android](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization).

Release-сборка требует больше времени на компьютере разработчика из-за R8. Для диагностики ошибок нужно сохранять файл mapping для каждой версии. При подготовке выпуска его сжатая копия помещается рядом с APK в `dist/`.

## Повторное отображение страниц

Раньше ключ кэша зависел от запрошенной ширины. Однако лимит в 4 млн пикселей приводит к тому, что разные большие масштабы дают одинаковое фактическое разрешение. Например, для страницы 595 × 842 запросы ширины 2200, 3000 и 12000 дают одно и то же изображение 1681 × 2379.

Теперь ключ состоит из номера страницы и фактических размеров результата. Повторный запрос совпадающего изображения не вызывает нативный рендер, передачу пикселей между процессами и выделение нового bitmap. Размер кэша остаётся 24 МиБ; качество и ограничения безопасности сохранены. Android-тест проверяет идентичность возвращённого bitmap для таких запросов и отдельное изображение для меньшего разрешения.

## Запуск

Измерялся `TotalTime` команды `adb shell am start -S -W -n com.taktey.simplepdfreader/.MainActivity` на эмуляторе Pixel 7, Android 14/API 34, arm64. Это время запуска Activity до первого отображения, без открытия PDF. Перед каждым измерением процесс останавливался; системный файловый кэш не очищался. Первый запуск каждой версии отброшен, затем взято семь измерений. Сборки во время замеров не выполнялись.

| Версия | Медиана | Диапазон |
| --- | ---: | ---: |
| 0.3.0 | 766 мс | 732–856 мс |
| 0.3.1 | 721 мс | 575–907 мс |

Разброс велик, диапазоны перекрываются, порядок измерений не рандомизирован. Эти данные **не подтверждают устойчивое ускорение запуска** и не прогнозируют скорость на физическом телефоне. Исходные измерения: [0.3.0](performance/startup-v030.json), [0.3.1](performance/startup-v031.json).

Для следующего этапа оптимизации скорости нужны замеры на целевом телефоне: открытие большого сканированного PDF, прокрутка и масштабирование, пропущенные кадры и пиковая память. Предварительная отрисовка дополнительных страниц или увеличение кэша без таких измерений могут увеличить потребление ресурсов.
