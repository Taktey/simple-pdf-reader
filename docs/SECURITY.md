# Защита документов в версии 0.3.0

PDF разбирается системным `PdfRenderer` в отдельной службе с `isolatedProcess=true`. Служба получает дескриптор только открытого документа, доступный только для чтения. Она работает под отдельным UID без разрешений приложения. Основной процесс получает ограниченные сырые пиксели, а не PDF или сжатые изображения. Канал передачи создаёт основной процесс; служба получает только его пишущий конец. Размер результата проверяется до выделения памяти: максимум 4 млн пикселей, ширина до 4096, высота до 8192.

На открытие/страницу отведено 15 секунд. Отдельный watchdog завершает зависший процесс; клиент также ограничивает ожидание ответа и чтение пикселей. После сбоя документ нужно открыть заново. Это ограничивает последствия ошибок системного PDF-движка, но не заменяет обновления безопасности Android и не доказывает отсутствие всех уязвимостей.

Импорт `content://` выполняется в отдельном приватном процессе с UID приложения, поскольку ему нужны временные разрешения Android на чтение URI. Проверяются MIME, сигнатура `%PDF-` в первых 1024 байтах и фактическое число прочитанных байтов. Максимум — 200 МиБ. Через 45 секунд процесс останавливается. Отмена закрывает привязку к службе и завершает её процесс даже при заблокированном чтении провайдера. Обычный `CancellationSignal` используется дополнительно.

## Локальные копии

- Документы и копии для отправки вместе занимают до 500 МиБ; перед импортом резервируется место под максимальный файл и ещё 50 МиБ свободного пространства. Поэтому маленький документ тоже может потребовать до 250 МиБ свободного места.
- При недостатке места удаляются самые давно открытые документы, кроме защищённой текущей копии. Одинаковое содержимое определяется по SHA-256 и хранится один раз.
- Копии документов старше семи дней очищаются при обновлении истории/импорте. В истории видны последние 20 документов.
- В разделе «Недавние документы» можно удалить одну локальную копию или все копии. Эти действия требуют подтверждения. Исходные файлы вне приложения не изменяются.
- Подготовка отправки создаёт отдельную копию с непредсказуемым именем каталога. `FileProvider` разрешает только чтение этой области; обычные документы не публикуются.
- Через 24 часа новые открытия URI отправленной копии запрещаются. Физическая очистка выполняется при следующем обращении к хранилищу. Уже открытый получателем дескриптор или скачанный им файл отозвать нельзя. Полная очистка удаляет и копии для отправки.
- Приложение не запрашивает доступ к интернету, не содержит аналитики; резервное копирование/перенос данных отключены. Включаемый на главном экране запрет снимков использует `FLAG_SECURE` и сохраняется между запусками.

## Выпуск и зависимости

Release APK не допускает отладку и подписан постоянным RSA-ключом 3072 бита. Ключ находится в `.signing/`, настройки — в `signing.properties`; оба пути исключены из Git. Владелец должен сохранить их защищённую резервную копию: без этого ключа нельзя выпускать совместимые обновления установленной release-версии.

SHA-256 сертификата выпуска:

```
fe540e691080d53bed8151e3e518e1042e740ab81456bfecc8f17eac39184cc9
```

В `gradle-wrapper.properties` закреплён SHA-256 дистрибутива Gradle. `gradle/verification-metadata.xml` содержит SHA-256 артефактов и метаданных зависимостей. Обычная сборка проверяет их в строгом режиме. Первичный набор создан по локальному кэшу и артефактам настроенных Maven-репозиториев; это фиксация исходного состояния, а не независимый аудит происхождения каждого артефакта. При обновлении зависимостей изменения контрольных сумм нужно проверять до принятия. Не отключайте проверку для обхода ошибок.

Инъекция зависаний находится только в `src/debug`; соответствующих служб и провайдеров нет в release APK. Проверки и фактические ограничения перечислены в [VALIDATION.md](VALIDATION.md).

Основание архитектуры: [рекомендация Android для недоверенных PDF](https://developer.android.com/reference/android/graphics/pdf/PdfRenderer), [изолированные службы Android](https://developer.android.com/guide/topics/manifest/service-element#isolated), [проверка зависимостей Gradle](https://docs.gradle.org/current/userguide/dependency_verification.html).
